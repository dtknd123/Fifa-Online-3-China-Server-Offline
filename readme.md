Đợt trước mình đã chia sẻ cho ae bản Server offline của bản Thái Lan

Hôm nay mình sẽ chia sẻ cho ae bản Server offline với Client của FO3 Trung Quốc nhé

Bản này mình đã Anh hoá toàn bộ thẻ cầu thủ rồi, Việt hoá sẵn ngôn ngữ luôn

Mình sẽ hướng dẫn các bạn tải client và cài đặt server offline nhé

Các bạn làm theo các bước sau đây:

Bước 1: Tải vài giải nén Client FO3 Trung Quốc theo link mình để ở dưới mô tả video nhé
https://archive.org/download/fifaonline3-client/%5BArchive%5D%20FIFA%20Online%203%20Client/FO3CN.rar

Bước 2: Tải và cài đặt Python (Bỏ qua bước này nếu đã cài đặt trước đó)

Bước 3: Tải Bản server offline về và giải nén theo link github mình để ở dưới phần mô tả video

Bước 4: Thực hiện copy bản server đã giải nén vào thư mục game theo video nhé

Bước 5: Thực hiện chạy file 1_Cai_Dat_Hosts.bat với quyền administrator

Bước 6: Thực hiện chạy file 2_Choi_Game_Offline.bat để khởi động game

Vậy là đã xong rồi đó, mời các bạn thưởng thức game, chúc các bạn chơi game vui vẻ.
